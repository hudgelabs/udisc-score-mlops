# 🥏 UDisc Score Prediction Pipeline

A production-ready MLOps project that predicts disc golf round scores based on course metrics and seasonal data.

## 🛠 Tech Stack
*   **Version Control:** Git & DVC (Data Version Control)
*   **Experiment Tracking:** MLflow
*   **API Framework:** FastAPI
*   **Containerization:** Docker
*   **CI/CD:** GitHub Actions
*   **Model:** Scikit-learn (Random Forest Regressor)

## 🚀 How it Works
1. **DVC Pipeline:** Reproducible stages for preprocessing and training.
2. **MLflow Tracking:** Logs R² scores and model artifacts.
3. **Automated Tests:** GitHub Actions runs unit tests on every push.
